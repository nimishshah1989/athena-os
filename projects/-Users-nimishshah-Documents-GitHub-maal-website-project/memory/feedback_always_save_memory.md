RULE: At the end of every session on this project, ALWAYS save:
1. What was discussed and decided
2. What was built or changed
3. What the next steps are
4. Any design/architecture decisions made

Never assume "the code speaks for itself" — save the WHY behind decisions, not just the WHAT.
