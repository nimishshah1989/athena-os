## Universe Page Design Preferences (March 2026)

- **No childish icons** — no emojis next to labels, keep it classy
- **No gray backgrounds** — everything white with card borders
- **Section band colors**: teal (#0f766e), blue (#1e40af), sky (#0369a1), slate (#475569). User rejected purple (#6d28d9) and maroon/rose (#9f1239) as "off"
- **Data spectrum colors** for cap allocation bars: emerald (#047857) Large, teal (#0d9488) Mid, amber (#d97706) Small
- **No "tab" word** — use colored left-border section separators
- **Symmetric card alignment** — all cards must form consistent grid blocks
- **Only build what can be delivered exactly** — user dislikes seeing mockups that can't be replicated
- **Line charts in Compare** — historical returns curve and rolling risk against benchmark
