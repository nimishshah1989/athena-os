Nimish provided a comprehensive PDF review of MF Pulse V1 on 2026-03-31. Key themes:

1. **Information density too low** — too much empty space, cards too big, fonts too small. Wants Bloomberg-terminal density with good readability.
2. **Data without context is useless** — raw metrics (skewness, kurtosis, Sharpe) need interpretation/commentary. Every number should be actionable or explained.
3. **Universal filters must work globally** — Regular/Direct, Equity/Debt/Hybrid, AUM size filters on Dashboard should apply across ALL pages.
4. **"Other" categories always last** — in every table/list, "Other" must sort to bottom.
5. **Performance is critical** — pages load too slow. Wants server-side caching since data refreshes daily, not live.
6. **Design inconsistency** — colors, fonts, card sizes, table styles vary across pages. Needs one standardized design language.
7. **Peer logic broken** — ICICI Pru MidCap showing Aditya Birla funds as peers. Category-based peer matching needs fixing.
8. **Simulation/Strategy merge** — Remove Simulate tab, merge into Strategy Builder.
9. **Strategy logic bugs** — SIP + lumpsum summing incorrectly; lumpsum should be trigger-based, separate from SIP.
10. **Info icons (i) everywhere** — every column, chart, metric needs tooltip explaining what it is, how to read it, formula if derived.

**Why:** This is the founder's comprehensive review before the tool goes to production use. Every item matters.
**How to apply:** This is the binding requirements list for V2. Treat as acceptance criteria — every item must be addressed before deployment.
