name: RS Score as ratio not percentile
description: User wants RS Score as simple relative return ratio (% return vs benchmark minus 1), not percentile rank
type: feedback
---

RS Score should be: (sector_return / benchmark_return) - 1, expressed as percentage.
Positive = outperforming benchmark, negative = underperforming.
NOT a 0-100 percentile rank across the universe.
This is more intuitive — shows exactly how much a sector is beating/lagging the benchmark.
